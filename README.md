# Классификация гистологических изображений

Практическое задание №1 по курсу «Нейронные сети в обработке изображений. Вводный курс».

## Описание решения

Для классификации гистологических изображений на 9 классов используется свёрточная нейронная сеть ResNet18 с предобученными весами ImageNet.

Последний полносвязный слой заменён на слой с 9 выходами. Обучение проводится в PyTorch на GPU с использованием AdamW (learning rate = 0.0001) и CrossEntropyLoss.

Для обучения использовался набор `train_small` из 7200 изображений. 15% данных выделены для валидации. Модель обучалась 8 эпох, размер батча — 64. В качестве аугментаций использовались случайные горизонтальные и вертикальные отражения.

Лучшая модель выбиралась по Accuracy на валидационной выборке и сохранялась после улучшения результата.

## Результаты

| Набор данных | Accuracy |
|---|---|
| Validation | 98.80% |
| test_small | 98.56% |
| test | 98.47% |
| test_tiny | 97.78% |

Лучший результат на валидации получен после 5-й эпохи.

Дополнительно построены графики обучения, матрица ошибок и отчёт с Precision, Recall и F1-score для каждого класса.

## Запуск

Решение находится в ноутбуке `histology_classification.ipynb`.

Для запуска рекомендуется Google Colab с GPU. Необходимые библиотеки устанавливаются в начале ноутбука, а датасеты загружаются автоматически.

Для загрузки уже обученной модели используется:

```python
model = Model()
model.load('best')
```

Метод `load()` автоматически скачивает обученные веса из публичного Google Drive. Повторное обучение для тестирования не требуется.
